# Personal Finance Power BI Dashboard

## Project Overview

This project presents an interactive Personal Finance Dashboard developed using Microsoft Power BI, DAX, and Excel.

The dashboard is designed to provide a clear view of income, expenses, savings, financial performance, and changes over time.

## Dashboard Pages

### 1. Executive Dashboard

The Executive Dashboard provides a high-level overview of financial performance, including:

- Total Value
- Total Income
- Total Savings
- Total Expenses
- Savings Percentage
- Savings breakdown by component
- Expense breakdown by category
- Income, Expenses, Savings and Target trends over time
- Year-based filtering
- Month-over-month income change

### 2. Income vs Expense Analysis

This page provides a deeper analysis of income and expenditure, including:

- Income
- Expenses
- Savings
- Savings Rate
- Income vs Expenses by month
- Variance
- Variance Percentage
- Financial Status
- Waterfall analysis

The project applies DAX measures for:
